# Baobab Experience UI — BXS-04

Portable, SSR-safe native HTML components without Radix/Base UI lock-in. Includes a safe default button, breadcrumbs, native disclosure, feedback states, status labels and ordered milestone timelines. Components never authorise an actor, derive a legal fact or claim success for a pending operation.

Node 24 and pnpm 11.24.0 are required. Build with pnpm --filter @baobab-platform/experience-ui test. Opt into the published JS export and styles.css along with experience-tokens/base.css and an approved theme. The package contains CSF3 stories for consumption by estate-owned Storybook; this is not yet a running Shared Storybook app or a browser visual-regression receipt. Those remain explicit BXS-04 acceptance work.
